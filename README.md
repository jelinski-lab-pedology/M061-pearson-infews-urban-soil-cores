# Impacts of Urban Food Production on Chemical and Physical Properties of Urban Soils

Soil properties in Minneapolis–St. Paul urban soils, across community gardens/urban farms, parks and green spaces, and residential sites.

## Project Description and Funding

<!-- TODO: replace with final abstract once manuscript is complete -->
In a changing climate, urban food production will become increasingly important to support the planet's growing population. To support that, land users and managers require soil data. This project investigated trends in key soil properties across land use and land cover, with a special emphasis on the impacts of urban food production. Between 2018 and 2022, soil samples were collected from parks and green spaces, residential sites, and community gardens/urban farms in Minneapolis and St. Paul, Minnesota, to evaluate urban agriculture as a viable green infrastructure practice.

This work was made possible by US Department of Agriculture award 20196701930463 to A. Ramaswami, “INFEWS/T1: Sustainable Urban Food (SURF) Actions for Environment, Health, Equity, and Resilience at the FEW Nexus - Linking Distributed Urban Agriculture, New Technologies and Behavioral Nudges.

## Data Availability

Raw and prepared data in `00-data/` include soil property measurements (total carbon, lead, phosphorus, pH, bulk density, Ksat) and site-level metadata (year, site/plot ID, site type, land use). **Precise site coordinates (latitude/longitude) and identifying information (addresses, site/farmer names, and field notes) have been withheld from this public repository** to protect participant privacy. A complete version of the site-level dataset is retained by the authors.

Because the site-type and land-use maps (`02-output/a-figures/site-type-map07AUG2025.png`, `land-use-map07AUG2025.png`) were generated from the unredacted coordinates, the code that produced them (`03-support-files/archive/x000-site-maps.R`) cannot be re-run on the public data — it is retained for transparency, and the rendered maps are included as final outputs.

## Reproducing the Analysis

The full analysis pipeline can be run from `01-code/a-Rscripts/000-primary.R`, which sources each script in sequence:

1. `00-prepare-workspace.R` — loads required R packages
2. `01-load-in-and-inspect-data.R` — reads raw data from `00-data/a-raw/`
3. `02-data-munging.R` — cleaning, bulk density modeling, dataset preparation
4. `03-data-analysis.R` — Kruskal-Wallis / Dunn statistical analysis
5. `04-stock-calculations.R` — carbon/phosphorus stock calculations
6. `05-output-figures.R` — figure generation
7. `06-output-tables.R` — summary table generation

Open `M061-pearson-infews-urban-soil-cores.Rproj` in RStudio first so that relative paths (via the `here` package) resolve correctly. Required packages: `tibble`, `dplyr`, `here`, `terra`, `ggplot2`, `patchwork`, `gt`, `webshot2`, `ggmap`, `dunn.test`, `tidyr`. Map generation (archived script only) additionally requires a [Stadia Maps API key](https://client.stadiamaps.com/).
